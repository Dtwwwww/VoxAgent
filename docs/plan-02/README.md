# Plan 2：混合实时语音运行与验收手册

Plan 2 在同一 WebSocket 会话中提供文字与连续语音对话。文字输入始终只返回文字；实时通话默认优先使用浏览器中文语音能力，能力不可用或在线识别失败时自动切换到本地 SenseVoice/Paraformer 与 Kokoro。Ollama、VoxAgent 后端和本地语音链路只监听本机回环地址。

## 当前配置

- Web 前端：`http://127.0.0.1:5173`
- 后端：`127.0.0.1:8765`
- Ollama：`127.0.0.1:11434`
- 本地模型：`qwen3:4b-instruct-2507-q4_K_M`
- 默认模式：在线优先
- 本地公开音色：`default_voice`（声灵默认音色，Kokoro voice 3）
- 停顿策略：正常句尾约 1–1.5 秒自动提交，未完成句尾最多约 2 秒

Melo 已从用户可见音色和生产初始化中移除。目标机器的合成后回识别结果不可懂；Kokoro 中文可懂，但 CPU 合成明显较慢，因此只作为本地回退，不承诺浏览器语音同等延迟。

## 手动启动

打开三个 PowerShell 窗口，所有命令都在本项目工作树根目录执行。只启动或重启 VoxAgent 的 Ollama、后端和 Vite，不要结束 GPT、Codex、Roxi、ToDesk、NVIDIA 或其他无关进程。

窗口 1：启动 Ollama。若 11434 已经监听，可跳过 `Start-Process`。

```powershell
$env:OLLAMA_MODELS = 'D:\VoxAgentData\models\ollama'
$env:OLLAMA_NO_CLOUD = '1'
$env:OLLAMA_HOST = '127.0.0.1:11434'

if (-not (Test-NetConnection 127.0.0.1 -Port 11434 -InformationLevel Quiet)) {
    Start-Process -FilePath 'D:\VoxAgentData\runtime\ollama\ollama.exe' `
      -ArgumentList 'serve' -WindowStyle Hidden
}
```

生成一次临时 token，并复制输出值。后端命令和浏览器 URL 必须复用这一个值；不要提交到 Git，也不要写入 `localStorage`。

```powershell
$token = [Convert]::ToBase64String(
    [Security.Cryptography.RandomNumberGenerator]::GetBytes(32)
).TrimEnd('=').Replace('+','-').Replace('/','_')
$token
```

窗口 2：把上一步输出粘贴给 `$token`，启动后端。首次连接时，本地语音模型初始化可能需要十几秒。

```powershell
$token = '粘贴刚才生成的 token'
$env:VOXAGENT_DATA_ROOT = 'D:\VoxAgentData'
Set-Location '.\backend'
& '.\.venv\Scripts\voxagent.exe' serve --session-token $token --port 8765
```

窗口 3：启动 Web 前端。

```powershell
Set-Location '.\frontend'
& '.\node_modules\.bin\vite.cmd' --host 127.0.0.1 --port 5173
```

浏览器打开下面地址，并把末尾替换为同一个 token：

```text
http://127.0.0.1:5173/?token=粘贴刚才生成的token
```

## 选择 Realtek 麦克风

1. 首次点击“开始实时通话”时允许浏览器使用麦克风。浏览器隐藏设备名时，VoxAgent 会先打开并立即停止一次授权流，再重新读取带名称的设备清单。
2. 在“麦克风”下拉框选择“麦克风阵列 (Realtek(R) Audio)”。若系统显示为 “Microphone Array (Realtek(R) Audio)”，选择该同一设备；随后实际采集会按该 `deviceId` 精确打开新音轨。
3. 对着电脑说话，确认旁边百分比和音量条变化。选择结果和实际 `MediaTrackSettings` 只用于本页诊断；刷新后应继续选中该设备。

ToDesk、XReal、VB-Audio、Stereo Mix 以及名称含 Virtual 的输入会标记“虚拟”。它们是远程桌面、扩展现实或音频路由产生的逻辑设备，不等同于笔记本内置麦克风；误选时可能得到静音或其他应用的音频。它们不会被删除，必要时仍可手动选择。

## 模式、回退与使用方式

- “在线优先”：先使用浏览器提供的中文连续识别和系统/在线中文音色。浏览器不支持、外网不可用、识别网络错误或没有可用中文音色时，会保留当前会话并自动回退本地链路。
- “仅本地”：不启动浏览器在线识别或非本机语音服务；PCM 只发送到 `127.0.0.1` 的 VoxAgent 后端，由本地 ASR、Ollama 和 Kokoro 处理。
- 通话进行中可以直接切换“在线优先”与“仅本地”。切换复用当前 WebSocket、会话历史和麦克风采集，不会新建会话；即使麦克风仍在授权/连接中，也以最后一次模式选择为准，旧识别/朗读回调会失效。首次从本地切回在线时仍须确认在线语音说明。
- 自动回退时，状态区显示“已切换到本地语音”，提供器变为本地。Kokoro 生成较慢；即使朗读失败，已完成的回答文字仍保留，通话恢复监听。
- 点击“开始实时通话”一次后持续监听。临时字幕显示为“用户（识别中）”，最终字幕只固化为一条“用户”消息；正常停顿会自动提交。
- Agent 回答按完整短句依次朗读；`assistant.done` 也会朗读最后一段没有句号的文字。流式分段会跨增量跟踪 fenced code、inline code、Markdown 链接和 URL 查询串，只在结构外的安全原文边界切分；代码、URL 与 emoji 只从朗读副本移除，聊天气泡仍显示完整原文。
- 浏览器中文音色缺失、加载后仍为空、仅有非中文音色或已选中文音色消失时，不会静默改用错误音色，而会一次性回退 Kokoro。若前半段已成功朗读，本地使用同一 Unicode code-point 安全边界，只规范化并朗读服务端保存回答的剩余后缀。
- 在底部输入框提交文字时，无论当前选择哪种模式或实时通话是否开启，回答都保持静音。
- Agent 消息上的朗读按钮仍可单独重播；浏览器只接收与实时回答相同规则生成的朗读副本，纯代码/emoji 等无可朗读内容保持静音，重播失败时按同一浏览器到 Kokoro 回退规则处理。
- 浏览器合成由会话 controller 按原生全局队列统一串行管理。实时通话中的“停止朗读”、用户开口打断或切换“仅本地”都会取消当前手动重放且不会触发意外 fallback；关闭音色选择器只按 preview owner 取消仍在进行的试听，不会停止后来开始的实时/手动朗读，也不会取消对话轮次。

## 隐私说明

- 在线优先的浏览器识别或合成可能由浏览器/操作系统的平台在线服务处理语音。项目没有为此配置、保存或发送第三方语音 API Key；具体网络处理受所用浏览器和平台的隐私条款约束。
- 仅本地模式不调用浏览器在线识别或非本机语音服务。Ollama、后端和 PCM WebSocket 均使用本机回环地址。
- VoxAgent 不持久化原始麦克风音频。浏览器本地设置只保存模式、所选设备 ID/显示名称、语速和公开音色选择。
- 会话 token 只用于当前后端和 URL，不写入浏览器设置。`/healthz` 不公开 token、模型路径或私有音色编号。

## 音量条不动时

音量反馈目标是在开始采集后 100 ms 内变化。若音量条持续为零：

1. 确认下拉框选中 Realtek 麦克风阵列，而不是带“虚拟”的 ToDesk/XReal 等设备。
2. 在浏览器地址栏的站点权限和 Windows 隐私设置中确认该浏览器获准使用麦克风。
3. 打开 Windows“设置 → 系统 → 声音 → 输入”，选择同一 Realtek 麦克风，确认系统输入音量条会动且输入音量不为零。
4. 结束通话后重新选择 Realtek 并开始；若设备刚插拔，刷新页面后再选。
5. 仍无变化时，关闭正在独占麦克风的录音/会议应用，保留 VoxAgent 服务运行，然后重试。连续 3 秒检测不到声音时，界面也会提示检查麦克风。

## 其他故障排查

- “token 验证失败”：确认后端的 `--session-token` 与网页 URL 中的 token 完全相同。
- “已有一次会话”：关闭其他 VoxAgent 页面后刷新。
- “无法连接语音服务”：确认 8765 端口正在监听，并查看后端窗口错误。
- 首次连接停在初始化：通常需等待十几秒；若随后显示初始化失败，检查 `D:\VoxAgentData\models\speech` 和后端日志。
- 在线语音失败但没有回退：确认通话仍处于“在线优先”，记录状态栏提示和浏览器版本；可切到“仅本地”继续使用。

## 停止

在后端和 Vite 的两个前台 PowerShell 窗口中分别按 `Ctrl+C`。不要结束 GPT、Codex、Roxi、ToDesk、NVIDIA 服务或其他无关进程。Ollama 可留在后台继续供本机模型使用。
