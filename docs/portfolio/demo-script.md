# VoxAgent 三分钟求职演示脚本

## 演示前准备

- 使用目标电脑，确认 Ollama、VoxAgent 后端和 Vite 都只监听 `127.0.0.1`，浏览器已用本次 Session Token 打开。
- 在设置中保持语音模式为“仅本地”，选择真实物理麦克风；关闭会议软件和可能独占麦克风的程序。
- 提前准备一个无版权、无隐私的 UTF-8 文本文件，内容如下：

```text
青禾计划演示手册
青禾计划的发布窗口是周五下午三点。
演示负责人是林舟，验收标准是回答必须显示引用来源。
```

- 新建或清空演示数据。录屏时隐藏带 Token 的地址栏，不展示本机绝对路径、数据库和日志原文。

## 三分钟流程

| 时间 | 操作 | 预期界面 | 讲解的工程取舍 | 失败时停止条件 |
| --- | --- | --- | --- | --- |
| 0:00–0:25 | 展示地址栏为 `127.0.0.1`（遮住 Token），快速打开设置确认“仅本地”；口述本机模型为 Qwen3 4B、本地 ASR 和 Kokoro | 页面已连接；模式显示“仅本地”；不出现外部 API Key | 目标是 6 GB 显存 / 16 GB RAM 的普通 Windows 电脑，因此模型、用户数据和语音默认留在本机 | 后端未连接、Ollama 模型身份校验失败或页面暴露 Token 时立即停止，不带病演示 |
| 0:25–0:50 | 输入“请用两句话说明你能做什么，并保持静默”，提交一轮文字问答 | 用户与模型消息进入同一时间线；回复流式出现且没有自动发声 | 文字输入显式设置 `speak_response: false`；文字与语音复用会话，但输出策略分离 | 连接关闭、回答自动朗读、消息重复或超过约 15 秒仍无首字时停止并记录现象 |
| 0:50–1:30 | 打开“本地知识库”，导入准备好的公开示例文件；提问“青禾计划何时发布，谁负责？请给出处” | 导入完成；回答包含“周五下午三点”“林舟”，消息下方可展开命中文档片段 | 文档先解析、分段和本地向量化，再用单事务落库；引用让检索证据可核对，文档内容按不可信数据处理 | 导入失败、引用未显示、答案与片段矛盾或出现本机绝对路径时停止，不把幻觉当成功 |
| 1:30–2:05 | 打开“设置 → 记忆”，新增“演示偏好：回答先给结论”；改为“演示偏好：先给结论，再给依据”；最后删除 | 三次操作后列表依次出现、更新、消失；无敏感信息 | 记忆可审查、可编辑、可删除；对话建议还需确认，后端另有敏感内容策略 | 任一步未持久化、编辑产生重复项、删除后刷新仍存在或错误泄露数据时停止 |
| 2:05–3:00 | 点击开始本地实时通话，说“请简短复述刚才的发布信息”；模型开始朗读后立刻开口说“停，请只说负责人” | 有输入电平和临时字幕；最终字幕只固化一次；旧朗读被取消且不恢复，新一轮继续 | 插话依靠 turn / request / generation 所有权隔离迟到回调；本地 Kokoro 首段约 3.9 秒是已知瓶颈，要主动披露 | 输入条不动、最终字幕重复、旧声音恢复、转到浏览器在线语音，或模型初始化 / 首段等待明显失控时停止 |

## JR-02 Agent MVP 加演（约 60 秒）

1. 输入“创建提醒：今晚复习 Agent”，确认页面只显示工具名、L2 和“仅允许本次执行”，不显示参数编辑框。
2. 先演示一次“拒绝”，确认出现失败状态且提醒没有创建；再次发起后点击“允许一次”，确认依次出现正在执行和已完成。
3. 打开“设置 → 工具审计”，展示 request、confirmation、started/succeeded 等事件；只展示耗时、错误码和恢复状态，不展示参数、绝对路径或 Token。
4. 说明 Tool Registry 启动后冻结，每轮最多 3 次工具调用和 8 次图节点；项目没有 Shell、PowerShell、删除文件或安装软件工具。

## 收尾话术

“这版证明了我能把 FastAPI、WebSocket、本地模型、RAG、记忆、实时语音和带权限确认的单 Agent 做成可验证闭环。当前没有把原生工具注册表冒充成 MCP，也没有把 12 条 fake 冒烟评测冒充成真实模型稳定性结论；下一步会补 MCP、Hybrid RAG、正式评测、可观测和交付证据。”

演示只证明一次真实路径。面试官若要复核工程质量，在仓库根目录运行：

```powershell
& .\scripts\verify.ps1 -Scope All
```
