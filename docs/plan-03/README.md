# Plan 3：记忆与本地知识库使用手册

Plan 3 在 Plan 2 的本地文字/语音对话上增加长期记忆、单一人格、本地文档检索、数据导出、完整清空和每日备份。嵌入、检索和数据管理均在本机完成；运行模型和用户数据不会提交到 GitHub。

## 启动

启动方式与 Plan 2 相同，详见 [`../plan-02/README.md`](../plan-02/README.md)。后端启动时会自动迁移数据库；无需单独运行数据库命令。

首次启用知识库前，在仓库根目录下载并校验本地嵌入模型：

```powershell
& .\scripts\download_embedding_model.ps1 -DataRoot 'D:\VoxAgentData'
```

脚本使用仓库内锁定的模型版本和 SHA-256 校验值；已正确下载时会安全跳过。

默认数据位置：

- 数据库：`D:\VoxAgentData\data\voxagent.db`
- 每日备份：`D:\VoxAgentData\data\backups`
- 临时导出：`D:\VoxAgentData\data\exports`
- 本地嵌入模型：`D:\VoxAgentData\models\embeddings\bge-small-zh-v1.5`

## Web 入口

- 点击顶部书本按钮打开“本地知识库”。
- 点击顶部设置按钮打开“声灵设置”，其中包含“人格”“记忆”“数据”三个标签。
- 面板只有在打开时才读取对应数据。

## 人格

“人格”面板可修改名称、对用户的称呼、背景、性格、关系定位、表达风格、主动程度、边界和默认回复长度。保存后从下一次回复开始生效。固定的隐私、安全和工具边界不会被人格内容覆盖。

## 长期记忆

- 对话结束后，声灵可能显示“要记住这件事吗？”；选择“保存记忆”后才会持久化，选择“不保存”则丢弃建议。
- 密码、令牌、支付信息、证件号和医疗诊断等内容会被后端策略拦截，即使前端请求保存也不能绕过。
- 在“设置 → 记忆”中可手动添加、编辑和删除记忆。
- 从对话建议保存的记忆会显示来源轮次，便于追溯。

## 本地知识库

1. 打开顶部“本地知识库”。
2. 点击“添加文档”，选择 TXT、Markdown、文本 PDF 或 DOCX；单个文件上限 20 MB。
3. 导入过程中可点击“取消导入”；导入完成后，可点击“查看”分页检查全部分段文本，也可删除整个文档。

回答使用过记忆或知识片段时，Agent 消息下方会出现“查看引用来源”，可核对具体片段以及记忆所依据的用户原话。

文档先完成解析和向量化，再在一个事务内写入数据库。相同内容不会重复导入；取消或失败不会留下半份索引。回答时最多注入四个相关片段，并把片段标记为不可信参考数据而非指令。Web 接口不会返回原始绝对路径。

## 导出、清空与备份

- “设置 → 数据 → 导出本地数据”会下载一个 ZIP，其中包含 UTF-8 JSON。向量属于可重建数据，不包含在导出文件中。
- “删除全部本地数据”必须准确输入 `删除声灵全部本地数据` 才可执行，并会清空人格、记忆、知识库、对话、导出文件和历史备份。
- 每个本地日期第一次正常退出后端时，会通过 SQLite 在线备份生成一份完整数据库备份，并执行完整性检查；只保留最新七份。
- 历史备份可在“数据”面板查看和单独删除。

## 隐私与限制

- API 和 WebSocket 都要求本次启动生成的同一 session token。
- 服务仅监听 `127.0.0.1`；允许的 Web 来源仅为本机 5173 端口。
- 目前只解析文本型 PDF，不对扫描图片执行 OCR。
- 删除知识文档只删除声灵数据库中的文本和向量，不删除用户原始文件。
