# BreezyVoice 前端音色接入实施计划

## 1. 目录与协议

- 扩展 `VoiceEngine`、音色目录校验和生产 catalog。
- 将 `breezy_tw_female` 加入公开音色列表，保持默认音色不变。
- 更新后端 TTS 分派接口，确保未知/缺失资源不会在启动阶段阻塞其他音色。

## 2. BreezyVoice 适配

- 新增独立适配模块，懒加载官方源码和本机模型路径。
- 增加配置解析、路径校验和可读错误。
- 通过后台线程执行 CPU 合成，并复用现有 WAV 音频输出协议。

## 3. 前端选择器

- 扩展音色卡片以区分实时音色与高质量非实时音色。
- 保持选择、持久化、试听、停止试听和错误回退行为一致。
- 增加组件测试覆盖新的音色。

## 4. 验证与发布

- 先运行后端目录/TTS 测试和前端类型检查、构建、针对性组件测试。
- 启动/检查现有服务，验证 `voices.available` 和选择事件。
- 只提交源代码、文档和配置模板，不提交模型文件、缓存和临时目录。
- 创建提交并推送当前分支到 GitHub；汇报远端分支和提交号。
